HOW TO PUBLISH (GitHub website, no commands)
1. Unzip this file.
2. In your GitHub repo "case": Add file > Upload files.
3. Drag in: index.html  AND  the whole "img" folder. (Upload img in 2 batches if GitHub complains about file count.)
4. Commit changes. Wait 2 minutes. Open https://sumtsang-ux.github.io/case/ (Ctrl+Shift+R to refresh).

_source = the editable project code. You do NOT need to upload it to GitHub Pages.
To update an image later: upload a new file with the SAME name into img/.
